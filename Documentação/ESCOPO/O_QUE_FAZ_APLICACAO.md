# 📱 O QUE FAZ A APLICAÇÃO

## Descrição Geral

A aplicação tem como objetivo simular um sistema de compras de produtos de informática, permitindo que os usuários realizem pedidos de forma simples e intuitiva.

---

## ⚙️ Funcionalidades Principais

- Cadastro de clientes
- Listagem de produtos
- Visualização de detalhes (nome, descrição, preço)
- Adição ao carrinho
- Gerenciamento do carrinho
- Cálculo automático do total
- Finalização de compra
- Histórico de pedidos

---

## 📱 Telas do Aplicativo

### 1. Tela de Produtos

- Lista de produtos em RecyclerView
- Exibição de nome, descrição e preço
- Ação de adicionar ao carrinho

---

### 2. Tela de Carrinho

- Lista de itens adicionados
- Controle de quantidade (+/-)
- Remoção de itens
- Exibição do valor total

---

### 3. Tela de Confirmação

- Resumo do pedido
- Lista de itens comprados
- Valor total
- Mensagem de sucesso
- Opção de iniciar nova compra

---

## 🔄 Fluxo de Uso

1. Usuário abre o aplicativo
2. Visualiza os produtos
3. Adiciona itens ao carrinho
4. Acessa o carrinho
5. Ajusta quantidades
6. Finaliza a compra
7. Visualiza a confirmação

---

## 🛠️ Tecnologias Utilizadas

- Android Studio
- Java
